# Otchłań (Abyss)

**[English](#english)** · **[Polski](#polski)**

<a id="english"></a>

## English

A roguelike in the spirit of *Brotato* and *The Binding of Isaac*. Engine: **Godot 4.7.2 (.NET)**, language: **C#**.
Version 2.0 is a rewrite and expansion of the original Python game (version 1.1). The work plan is in [`docs/PLAN.md`](docs/PLAN.md) (Polish).
The in-game text is currently Polish (an English version of the game is planned); English translations of names are given below in parentheses.

### Download the game (Windows)

A ready-to-play Windows build is produced automatically on every push: [**Actions**](https://github.com/hapsior/Abyss/actions) tab → latest successful “Build” run → **Artifacts** → **Otchlan-Windows** (requires being signed in to GitHub). Unzip and run `Otchlan.exe` – nothing needs to be installed.

### Running from source (Windows)

1. Install the **.NET SDK 8** (or newer): <https://dotnet.microsoft.com/download>.
2. Download **Godot 4.7.2 – .NET edition** (`Godot_v4.7.2-stable_mono_win64.zip`): <https://godotengine.org/download/archive/4.7.2-stable/>. Just unzip it, no installation needed.
3. In Godot: **Import** → select `project.godot` from this repository → **Import & Edit**.
4. Press **F5** to run the game. The C# code compiles automatically on start.

You can edit the code in Visual Studio, Rider or VS Code (Godot → Editor Settings → Dotnet → Editor sets the external editor).

### What is in the game (2.0)

- **40 floors in 8 biomes** (5 floors each, a boss on every 5th): Piwnice (Cellars), Katakumby (Catacombs), Zalane Groty (Flooded Caves), Kuźnia (Forge), Grzybnia (Mycelium), Lodowa Krypta (Ice Crypt), Mechanizm (Clockwork), Otchłań (the Abyss). Enemies are recoloured to match the biome. After floor 40 the **Głębia (Depths)** begins: endlessly generated, ever harder floors until you die.
- **8 bosses**: Król Glutów (Slime King), Licz (Lich), Matka Roju (Hive Mother), Władca Kuźni (Forge Lord), Matka Grzybni (Spore Mother), Szronowy Kolos (Frost Colossus), Zegarmistrz (Clockmaker), Serce Otchłani (Heart of the Abyss).
- **12 characters**: Rycerz (Knight), Łowczyni (Huntress), Berserker, Mag (Mage), Złodziej (Thief), Alchemik (Alchemist), Upadły (Fallen), plus new ones: Bard, Inżynier (Engineer – turrets), Szaman (Shaman – storm totem), Mnich (Monk – Ki Step), Rewolwerowiec (Gunslinger – 6-round cylinder).
- **74 items**, level-ups with reroll and banish, a shop opened by talking to the shopkeeper (interact button); items on pedestals are picked up with a button press.
- **71 achievements** with an in-game toast and an achievements screen (ready to be connected to Steam).
- **3 save slots**: the game saves automatically when moving between rooms and on exit; death deletes the slot.
- **Local co-op** on one screen (keyboard + mouse, the other half of the keyboard, or gamepads).
- **Gamepad**: once a pad is detected, prompts show Xbox buttons (A/B/X/Y, LB/RB, LT/RT); touching the keyboard or mouse switches them back to keys.
- **Display**: 1920×1080 base resolution scaled to any monitor (16:9, 21:9, 4:3); windowed, fullscreen, exclusive fullscreen, V-Sync and a frame limit of 60/120/144/165/240/unlimited.

| `src/Save` | Save slots, profile (unlocks, records) and achievement tracking. |
| `src/Platform` | Platform interface (local profile now, Steam later – see [`docs/STEAM.md`](docs/STEAM.md)). |
| `src/Audio` | Sound effects and music with crossfades. |
| `data/` | JSON data: characters, items, upgrades, enemies, bosses, biomes, difficulties, seals, achievements. |
| `art/` | SVG art in the style described in [`docs/ART_STYLE.md`](docs/ART_STYLE.md). |
| `audio/` | Sounds and music (generated by `tools/gen_audio.py`). |
| `assets/fonts` | Titan One and Baloo 2 (OFL licence, full Polish character set). |
| `tests/` | Tests run inside Godot, the bot and the balance simulator. |

| `legacy/` | The Python version (1.0 sources, 1.1 data) – reference for the rewrite. |

### Adding a boss / character / item

- **Boss**: an entry in `data/bosses.json` (attacks, phases, `hp_mult`), a class in `src/Sim/Bosses/` with `[EnemyType("key")]` deriving from `Boss` (template: `SporeMother.cs`), art in `art/bosses/key.svg`, biome assignment in `data/biomes.json`.
- **Character**: an entry in `data/characters.json` (stats, weapon, bullet, unlock condition), the ability in `PlayerSim.UseAbility`, art in `art/characters/` and `art/weapons/`.
- **Item**: an entry in `data/items.json` (stats named after `PlayerSim` fields, e.g. `damage`, `fire_mult`), icon in `art/items/key.svg`.

### Command line (QA)

```
godot --headless --path . -- --run-tests                     # tests, exit code 0 = OK
godot --path . -- --windowed --tour shots/                    # screenshots of menus, screens and a bot-driven run
godot --path . -- --windowed --boss-tour shots/ --bosses clockmaker   # a screenshot of every boss attack
godot --path . -- --windowed --char-tour shots/ --chars bard,mnich    # characters using their abilities
godot --path . -- --boss spore_mother                         # straight into a boss fight (no saving)
godot --headless --path . -- --balance out.csv --chars rycerz,mag --floors 45   # balance simulator
```

### Export (Windows)

In Godot: **Project → Export → Windows Desktop → Export Project** (the preset is in `export_presets.cfg`, output goes to `build/windows/Otchlan.exe`). Requires the 4.7.2 mono export templates (Editor → Manage Export Templates → Download). The `.github/workflows/build.yml` workflow does the same in GitHub Actions and publishes the `Otchlan-Windows` artifact (free for public repositories).

## Polski

Roguelike w stylu *Brotato* i *The Binding of Isaac*. Silnik **Godot 4.7.2 (.NET)**, język **C#**.
Wersja 2.0 to przepisanie gry z Pythona (wersja 1.1) i jej rozbudowa. Plan prac jest w [`docs/PLAN.md`](docs/PLAN.md).

### Pobierz grę (Windows)

Gotowa wersja na Windows powstaje automatycznie po każdym pushu: zakładka [**Actions**](https://github.com/hapsior/Abyss/actions) → ostatnie udane uruchomienie „Build” → sekcja **Artifacts** → **Otchlan-Windows** (trzeba być zalogowanym na GitHubie). Rozpakuj i uruchom `Otchlan.exe` – niczego nie trzeba instalować.

### Uruchomienie ze źródeł (Windows)

1. Zainstaluj **.NET SDK 8** (lub nowszy): <https://dotnet.microsoft.com/download>.
2. Pobierz **Godot 4.7.2 – wersja .NET** (`Godot_v4.7.2-stable_mono_win64.zip`): <https://godotengine.org/download/archive/4.7.2-stable/>. Wystarczy rozpakować, nie wymaga instalacji.
3. W Godocie: **Import** → wskaż plik `project.godot` z tego repo → **Import & Edit**.
4. Naciśnij **F5**, żeby uruchomić grę. Kod C# kompiluje się sam przy starcie.

Kod możesz edytować w Visual Studio, Riderze albo VS Code. Godot → Editor Settings → Dotnet → Editor pozwala ustawić zewnętrzny edytor.

### Co jest w grze (2.0)

- **40 pięter w 8 krainach** (po 5 pięter, boss na każdym 5.): Piwnice, Katakumby, Zalane Groty, Kuźnia, Grzybnia, Lodowa Krypta, Mechanizm, Otchłań. Wrogowie są przebarwieni pod krainę. Po 40. piętrze zaczyna się **Głębia**: piętra generowane bez końca, coraz trudniejsze, aż do śmierci.
- **8 bossów**: Król Glutów, Licz, Matka Roju, Władca Kuźni, Matka Grzybni, Szronowy Kolos, Zegarmistrz, Serce Otchłani.
- **12 postaci**: Rycerz, Łowczyni, Berserker, Mag, Złodziej, Alchemik, Upadły oraz nowe: Bard, Inżynier (wieżyczki), Szaman (totem burzy), Mnich (Krok Ki), Rewolwerowiec (bębenek na 6 naboi).
- **74 przedmioty**, awanse z losowaniem ponownie i odrzucaniem, sklep otwierany rozmową ze sklepikarzem (przycisk interakcji), przedmioty na piedestałach bierze się przyciskiem.
- **71 osiągnięć** z powiadomieniem w grze i ekranem osiągnięć (gotowe do podpięcia pod Steam).
- **3 sloty zapisu**: gra zapisuje się sama przy przejściu między pokojami i przy wyjściu; śmierć kasuje slot.
- **Co-op na jednym ekranie** (klawiatura + mysz, druga połowa klawiatury albo pady).
- **Pad**: po wykryciu pada podpowiedzi pokazują przyciski Xbox (A/B/X/Y, LB/RB, LT/RT); po dotknięciu klawiatury lub myszy wracają klawisze.
- **Ekran**: rozdzielczość bazowa 1920×1080 skalowana do każdego monitora (16:9, 21:9, 4:3); okno, pełny ekran, pełny ekran wyłączny, V-Sync i limit klatek 60/120/144/165/240/bez limitu.

### Nowy boss / postać / przedmiot

- **Boss**: wpis w `data/bosses.json` (ataki, fazy, `hp_mult`), klasa w `src/Sim/Bosses/` z `[EnemyType("klucz")]` dziedzicząca po `Boss` (wzorzec: `SporeMother.cs`), grafika `art/bosses/klucz.svg`, przypisanie do krainy w `data/biomes.json`.
- **Postać**: wpis w `data/characters.json` (statystyki, broń, pocisk, warunek odblokowania), umiejętność w `PlayerSim.UseAbility`, grafika w `art/characters/` i `art/weapons/`.
- **Przedmiot**: wpis w `data/items.json` (statystyki z `PlayerSim`, np. `damage`, `fire_mult`), ikona `art/items/klucz.svg`.
