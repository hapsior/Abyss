# Wersja w Pythonie (archiwum)

- `python-v1.0/` – pełne źródła wersji 1.0 (pygame-ce).
- `v1.1/data_dump.json` – wszystkie dane wersji 1.1 (postacie, przedmioty, wrogowie, bossowie, balans, osiągnięcia) odzyskane z buildu; źródła 1.1 nie przetrwały.
- `v1.1/INVENTORY.md` – spis modułów i funkcji wersji 1.1.
- `docs/` – dokumenty 1.1 (publikacja na Steam, instrukcja gracza). Kroki budowania dotyczą starej wersji; wiedza o Steamworks pozostaje aktualna.

Służy jako wzorzec przy przepisywaniu gry na Godota. Nie jest częścią projektu Godot (katalog ma `.gdignore`).
